# Riccardo Sanna Frutiger Aero Fotografia

A photography portfolio website styled in the Frutiger Aero aesthetic of the 2000s: glossy glass panels, bubbles, sky blues and fresh greens.

## About

I have always loved photography because it is a creative and calming activity. I also have a strong passion for the Frutiger Aero look, so I combined the two in this project.
